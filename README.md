# LZ-SHARE

Versión de LZ-PLUS para compartir: cada persona usa **su propia cuenta de AllDebrid**.
No trae claves, códigos ni configuraciones de nadie.

## Cómo se configura (la primera vez)

1. Necesitas una cuenta de AllDebrid con premium (alldebrid.com).
2. Abre LZ-SHARE y elige una opción:
   - **Conectar con un PIN** (recomendado en la TV): la app muestra un PIN; en tu celular entra a `alldebrid.com/pin`, inicia sesión y escríbelo.
   - **Escribir mi clave**: en alldebrid.com → *Apikey manager* crea una clave y pégala.
3. Listo: los servidores (Torrentio, Comet, catálogos, subtítulos y deportes en vivo) se configuran solos con tu cuenta.

Para cambiar de cuenta: Ajustes → *Mi cuenta de AllDebrid*.

## Notas

- Cada cuenta de AllDebrid es personal: no la compartas con otras casas.
- Usa los servidores y el contenido bajo tu propia responsabilidad.
- LZ-SHARE puede instalarse junto a LZ-PLUS sin chocar (usa el puerto 8090).
